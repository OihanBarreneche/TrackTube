Chargement des modules

Chaque module est réellement importé, et non compilé à la main. La différence n'est pas théorique : un contrôle par new Function compile en mode non strict, où une fonction déclarée deux fois est tolérée. Un module, lui, la refuse — et le doublon, invisible au contrôle, avait mis toute l'extension par terre.

Les modules qui touchent aux API de l'extension échouent forcément ici, faute de chrome.runtime : ce qui compte est la nature de l'erreur. Une erreur de syntaxe est un défaut ; une erreur d'exécution sur une API absente est attendue.
