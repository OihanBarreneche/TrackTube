# Changelog

## 1.1.1 — 9 October 2026

- Use English for the Chrome Web Store summary and small promotional image.
- No runtime behavior or local database schema change from 1.1.0.

## 1.1.0 — 9 October 2026

- Add three retrospective screens: comparison with the previous period, viewing
  delays by channel, and subscription activity.
- Allow exporting all retrospective cards together as a ZIP archive.
- Keep the extension's local database schema at version 7. An update of the same
  installed extension does not require an IndexedDB schema migration.

## 1.0.0 — 8 October 2026

- First public source release, with a chronological subscription feed, Shorts
  filtering, local viewing history, subscription sorting and backup import/export.
- Document known collection, preview playback and account-isolation limits in
  [docs/LIMITES.md](docs/LIMITES.md).

The Chrome Web Store release date may differ from these source release dates.
